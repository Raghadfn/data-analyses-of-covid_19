# 🌍 COVID-19 Global Data Analysis & Interactive Visualization

An advanced Python-based data analysis project designed to process and visualize global COVID-19 pandemic data interactively and professionally using **Pandas** and **Plotly**. The project utilizes reliable and updated open datasets to extract statistical insights and multi-dimensional visual charts.

---

## 🚀 Features & Included Visualizations

The script generates 4 interactive analytical dashboards and charts:
1. **Global Choropleth Map:** Displays the geographical distribution and scale of confirmed cases worldwide with hover details for deaths and recoveries.
2. **Global Timeline Trend:** A chronological line chart tracking the overall global progression of confirmed cases and deaths over time.
3. **Top 10 Affected Countries:** A bar chart comparing the countries with the highest recorded confirmed cases, featuring dynamic numerical formatting.
4. **Mortality Rate Analysis:** A scatter plot correlating the scale of confirmed cases with mortality rates for the top 20 affected countries, using bubble sizes to represent total deaths.
